# Vendored cl100k_base tokenizer data

`cl100k_base.tiktoken` is the OpenAI public tokenizer vocabulary downloaded from:

`https://openaipublic.blob.core.windows.net/encodings/cl100k_base.tiktoken`

- SHA-256: `223921b76ee99bde995b7ff738513eef100fb51d18c93597a113bcffe865b2a7`
- Retrieved for the pinned `tiktoken` 0.11 implementation.
- Runtime code verifies the checksum and never downloads tokenizer data.

The data is distributed with the tiktoken project under the adjacent MIT license notice.
