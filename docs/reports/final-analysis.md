## Claim gate

A research answer may move out of `PENDING_EVIDENCE` only when all of the following are
present in the same immutable cohort and lineage:

1. the exact experiment and configuration identifiers;
2. the estimand, sample count, point estimate, 95% confidence interval, and effect size;
3. overall and relevant question-type results from paired observations where applicable;
4. at least one inspected counterexample or an explicit statement that none occurred in the
   frozen inspection sample;
5. corpus, question-set, model, metric, and judge-calibration limitations;
6. a failure-sample record produced before inspection, with the required inspection order;
7. cost estimates including VAT, cached/new status, parse amortization, and an actual provider
   console reconciliation record for billing claims.

An interval crossing the declared practical-equivalence threshold is reported as
inconclusive. A small or unbalanced stratum is descriptive only. Gold outputs are never
re-tuned, and any output-changing defect invalidates the affected run.

## Failure inspection protocol

Inspect each planned item in this fixed order: original PDF, Standard parse, Enhanced parse,
chunks, rankings, answer, citations. Do not use the answer to decide how to interpret an
ambiguous source before checking the source and parses. The frozen labels are
`PARSER_ERROR`, `RETRIEVAL_MISS`, `CHUNK_BOUNDARY`, `TABLE_ERROR`, `RETRIEVAL_NOISE`,
`GENERATION_ERROR`, `HALLUCINATION`, `BAD_CITATION`, `FALSE_ABSTENTION`, and
`BENCHMARK_DEFECT`.

## Reproduction

Create a clean-snapshot `analysis-input-v1` JSON through an adapter that reads only completed,
immutable experiment IDs. Then run:

```bash
uv run python scripts/export_results.py \
  --input /path/to/immutable-analysis-bundle.json \
  --output data/exports/<immutable-analysis-id> \
  --public-salt '<release-specific-secret>'
```

Pass `--console-gross-usd` only from a recorded provider-console total covering the exact same
run boundary. The exporter refuses an existing destination or a symlink destination, writes
CSV and Parquet tables plus SVG figures, and publishes a SHA-256 manifest last.
